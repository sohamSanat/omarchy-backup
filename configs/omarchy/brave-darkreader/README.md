# Dark Reader (Omarchy) — Brave fork

Full Zen-treatment Dark Reader for Brave-Origin: every website dynamically
recolored from the active Omarchy system theme.

## What this is

Seeded from the installed Dark Reader 4.9.130 MV3 build, renamed to
`Dark Reader (Omarchy)` 4.9.130.1, with the Omarchy patches ported from
`~/.config/zen/mods/darkreader/src/` (same upstream version family, MV2→MV3
adapted):

- `background/index.js`: `OmarchyManager` (loads `config/omarchy-theme.json`,
  BT.601 luminance ground truth, pole-matched theme builder),
  `TOGGLE_OMARCHY_THEME` message, `toggleOmarchyTheme` /
  `refreshOmarchyThemeIfActive`, dark-list + detector bypass while active,
  Omarchy HSL color-math hooks in `_modifyBackgroundColor` /
  `_modifyForegroundColor`.
- `inject/index.js`: same color-math, `getOmarchyThemeOverrideStyle` (423-line
  YouTube/GitHub/Reddit/Dark Reader variable override sheet injected as
  `darkreader--omarchy-theme` in document + shadow roots), accent +
  `omarchyThemeActive` cache keys, detector guard.
- `ui/popup/`: `omarchy` toggle button + `omarchy-theme.css` (both generated),
  status text, settings validators.
- `config/omarchy-theme.json` + `ui/popup/omarchy-theme.css`: generated by
  `omarchy-sync-brave --sync` from `zen-darkreader-theme.json.tpl` /
  `zen-darkreader.css.tpl`. Do not hand-edit those two files.

Everything else is stock Dark Reader 4.9.130 and behaves exactly as upstream
when the Omarchy toggle is off (toggle restores the saved normal theme).

## Setup (one time)

1. `brave://extensions` → enable Developer mode.
2. **Load unpacked** → `~/.config/omarchy/brave-darkreader`.
3. **Disable the store "Dark Reader"** (two copies would double-process pages).
4. Open the fork's popup → press **omarchy** → every site re-themes navy.
   `omarchy-sync-brave --status` confirms the fork state.

After that, each `omarchy theme set <name>` refreshes the fork's tokens via
the theme-set hook; toggle off/on (or reload a tab) to rebuild page styles
with the new palette.
