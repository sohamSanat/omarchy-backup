EffectCraft motion graphics and visual effects compositor (After Effects-class). Every action is an engine command: `list_commands` or `describe_command` to discover, `execute_command` to run (undoable; `batch` runs several in one step). `get_project`, `get_comp`, and `get_layer` inspect the composition and layer hierarchy. `render_frame` renders a comp frame to PNG. When bridged to the running app (`--bridge`), synthetic UI events (`ui_inspect`, `ui_elements`, `ui_click`, `ui_drag`, `ui_key`) drive the live interface.
