WordCraft document processor. Clean-room reimplementation of Microsoft Word in pure Rust.
Interact with documents via `list_commands`, `execute`, `batch`, `new_document`, `open_document`, `save_document`, `type_text`, `select_text`, `get_text`, `inspect_document`, `render_page`, `parity`, and live UI inspection/interaction via `screenshot`, `click`, `key`, and `ui_inspect`.
Headless CLI automation via `wordcraft-cli`, and live control via loopback port 7981 (`wordcraft --control 7981`).
