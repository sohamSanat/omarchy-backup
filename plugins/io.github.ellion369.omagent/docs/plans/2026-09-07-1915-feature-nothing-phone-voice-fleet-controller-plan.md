# Nothing Phone Voice Fleet Controller (Mobile PWA)

## Goal Capsule

Enable seamless, hands-free voice control and real-time monitoring of the Linux agentic coding fleet (`Pi` + `Herdr` + `Firstmate` + `Treehouse` + `AXI` + `Compound Engineering`) directly from a **Nothing Phone** when away from the desk.

```
+-----------------------------------------------------------------------------------+
|                        NOTHING PHONE (Nothing OS)                                 |
|                                                                                   |
|  [Voice & Intercom Tab]       [Herdr Terminal Tab]       [Lavish Artifacts Tab]   |
|  * Pulsing Glyph Mic Button   * Live Terminal Viewer     * Interactive HTML/UI    |
|  * Nothing Keyboard Dictation * Read active Herdr pane   * Plans & Diagrams       |
|  * Live Highlight Stream      * Split / Zoom controls    * Review & Annotate      |
+----------------------------------------+------------------------------------------+
                                         | Secure Tailscale WireGuard Mesh
                                         v
+-----------------------------------------------------------------------------------+
|                     OMARCHY LINUX WORKSTATION (DAEMON)                            |

|                                        |                                          |
|            +---------------------------+---------------------------+              |
|            |                                                       |              |

|   (Lane 3 Coding Fleet)                                  (Panes / Workspaces)     |

+-----------------------------------------------------------------------------------+
```

## Product Contract

### 1. Scope & Core Requirements

1. **Secure Connectivity**:
   - Runs as a lightweight local daemon (`omagent-mobile-bridge`) bound to the workstation's Tailscale interface.
   - Zero port-forwarding or public exposure required; all communication is authenticated and encrypted via Tailscale mesh.
   - Serves an installable Progressive Web App (PWA) that can be pinned to the Nothing OS homescreen or launched via a lockscreen shortcut.

2. **Hybrid Voice Interaction**:
   - **Pulsing Glyph Push-to-Talk**: A prominent circular button styled after Nothing's Glyph Interface. Holding or tapping starts audio capture; releasing streams audio to the workstation's local Whisper engine for high-accuracy speech-to-text.
   - **Native Keyboard Voice Dictation**: A clean dot-matrix text input area allowing the user to use the Nothing Phone's native Gboard/Nothing keyboard voice-to-text button for instant local dictation, editing, or manual typing.
   - **Haptic Feedback**: Subtle vibration patterns on recording start, speech recognition completion, and task completion matching Nothing OS tactile feedback.

3. **Multi-Tab Mobile Command Center**:
   - **Tab 1: Voice & Intercom Stream (Default)**
     - Real-time bullet updates streamed via WebSocket from `omagent-route` (`• **Engaging** Compound Engineering: ce-work`, `• **Doing** ...`, `• **Completed** ...`).
     - Session history log showing recent user prompts and assistant actions.
     - Quick action buttons: `[Cancel Task]`, `[Approve PR]`, `[Expand in Herdr]`.
   - **Tab 2: Herdr Live Terminal Viewer**
     - Live, streaming text view of active Herdr workspaces and panes (`herdr pane read`).
     - Allows checking raw compiler errors, test executions, and CLI outputs directly from the phone.
     - Virtual keyboard shortcut bar for terminal navigation (<kbd>Ctrl+C</kbd>, <kbd>Enter</kbd>, <kbd>Up/Down</kbd>).
   - **Tab 3: Lavish Artifacts & Diffs**
     - Mobile-optimized viewer for `.lavish/*.html` artifacts generated by agents.
     - Renders responsive UI mockups, architecture flowcharts, and Markdown/HTML diffs.
     - Allows writing feedback notes on the phone that sync back to the agent session.

4. **Nothing OS Design System & Aesthetics**:
   - **Color Palette**: Pure dark background (`#000000`), monochrome white text (`#FFFFFF`), muted gray secondary text (`#7A7A7A`), and the signature Nothing Red accent (`#D71920`).
   - **Typography**: NDot 57 / Nothing dot-matrix font for headers and status tags, paired with clean monospace/sans for readable body text.
   - **Micro-Interactions**: Glyph pulsing rings during voice listening and agent processing; dot-matrix loading spinners.

### 2. User Workflows

#### Workflow A: Voice Task Dispatch on the Go
1. User opens the Nothing PWA from their homescreen or lockscreen widget.
2. User holds the Glyph mic button and speaks: *"Fix the authentication bug in auth.py and run the test suite."*
3. Upon release, audio is sent to workstation Whisper; transcription appears instantly.
4. Workstation classifies task into Lane 3 (`ce-debug`), spins up a Herdr workspace, and executes Pi.
5. Phone receives real-time highlight stream with haptic tick:
   - `• **Engaging** Compound Engineering skill: ce-debug`
   - `• **Doing** workspace setup in Herdr`
   - `• **Now doing** codebase & file inspection`
   - `• **Completed** ce-debug execution in Herdr`

#### Workflow B: Live Terminal Inspection
1. User switches to the **Herdr Tab** on their phone.
2. The phone displays the live output of the agent running inside the Herdr pane.
3. User can see unit tests executing or press `[Send Ctrl+C]` if they wish to abort execution.

#### Workflow C: Visual Plan & Mockup Review
1. The agent produces an architecture plan or UI prototype via `lavish-axi`.
2. A notification appears on the phone: `• **Visual Artifact Ready**: Open Review Surface`.
3. User taps into the **Artifacts Tab** to view the rendered HTML mockup or Mermaid diagram.
4. User taps `[Approve & Continue]`, signaling the agent to begin implementation.

### 3. Architecture & Component Boundaries

1. **Workstation Mobile Bridge (`omagent-mobile-bridge`)**:
   - Lightweight Python `asyncio` + `aiohttp` / `websockets` daemon.
   - Manages WebSocket sessions to connected mobile clients.
   - Interfaces directly with `omagent-route` and Herdr's Unix domain socket (`~/.config/herdr/herdr.sock`).
   - Managed via a user systemd service (`omagent-mobile-bridge.service`).

2. **Frontend Client (Mobile PWA)**:
   - Single-page vanilla HTML/CSS/JS or lightweight Alpine.js application with zero heavy dependencies.
   - Serves an offline-capable Web App Manifest with Nothing-styled SVG icons.
   - Uses Web Audio API for recording and WebSocket for streaming.

3. **Networking Boundary**:
   - Binds exclusively to the Tailscale IP (e.g., `100.x.y.z:7890`) or `localhost`.
   - Never exposes open ports to the public internet.

---

### 4. Success Criteria & Non-Goals

- **Success Criteria**:
  - Voice task dispatched from phone starts executing in Herdr within < 2 seconds.
  - Highlights stream to the phone screen with zero perceivable lag (< 200ms WebSocket latency).
  - PWA works reliably over cellular data via Tailscale.
  - Nothing OS aesthetic feels like a first-party Nothing application.
- **Non-Goals**:
  - Full mobile IDE code editing (reading and terminal viewing only; writing code is the agent's job).
  - Public cloud relay servers (strictly local/P2P via Tailscale).
